# Maintainers

TurnScope is currently maintained by [@appleweiping](https://github.com/appleweiping).

Maintainers review compatibility, determinism, security, documentation, and release evidence. Contributions are
accepted through pull requests; a maintainer remains accountable for every merged change. Repository ownership or
release access is granted only after sustained, reviewable contributions and is never implied by issue assignment.

Security reports must use [private vulnerability reporting](https://github.com/appleweiping/turnscope/security/advisories/new).
