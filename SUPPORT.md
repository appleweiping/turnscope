# Support

- Use [Discussions](https://github.com/appleweiping/turnscope/discussions) for usage questions and design ideas.
- Use [Issues](https://github.com/appleweiping/turnscope/issues) for reproducible defects and accepted feature work.
- Use [private vulnerability reporting](https://github.com/appleweiping/turnscope/security/advisories/new) for security concerns.

TurnScope is maintained on a best-effort basis. Public reports must contain a minimal sanitized example and must not
include private conversations, credentials, or regulated data.
