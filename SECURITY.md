# Security policy

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/appleweiping/turnscope/security/advisories/new) and include
affected versions, reproduction steps, impact, and any suggested mitigation. Maintainers
will acknowledge a complete report within seven days and coordinate disclosure after a fix is available.

TurnScope parses untrusted data but does not execute message text. Consumers remain responsible for file permissions,
resource limits, privacy controls, and safe handling of generated reports.
